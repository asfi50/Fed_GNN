# Fed_GNN Research Project Guidelines

This is a research-based project aiming to improve the current paper and develop enhancements.

When working on this repository, please adhere to the following instructions:
- **Understand the Codebase**: Always read `README.md` to understand the code structure and setup.
- **Understand the Paper**: Read `paper.md` to understand the original paper's concepts, methodologies, and findings.
- **Review Research History**: Check `research-logs.md` for a comprehensive log of all the research trials and experiments conducted so far before proposing or starting any new experiments.
- **Log Research Activities**: Whenever trying a new experiment or research approach, log it in `research-logs.md`. Record what was tried and the results in a compressed way, without losing essential details.
- **Response Format**: Your responses must always start with "Prof Asfi."
